### MEM-001 — RHS source is Monzo, not QuickBooks (OPERATIONAL)
Rex Home Services is ingested from raw Monzo Business CSV exports via `monzo_csv`, even though the seat's client-config originally assumed a QuickBooks extract. Monzo transactions ARE mirrored into QuickBooks downstream, so if a QB export is ever added as a source it would double-count — ingest one or the other, never both. Confirmed by Rex, 2026-07-14. See [[MEM-003]].

### MEM-002 — Mortgage letters carry no balance (OPERATIONAL)
The Barclays "Mortgage Payment Letter" PDFs are payment-change notifications with no outstanding-balance figure ("check your balance online"), so the `mortgage_pdf` source is disabled. The two Barclays mortgages are tracked as manual liability lines in `accounts.csv` with a negative `opening_balance` Rex maintains by hand.

### MEM-003 — Balances need anchoring; net-flow ≠ true balance (OPERATIONAL)
For any account built from a transaction feed, the engine's balance = `opening_balance` + net flow since the first transaction. With no opening seeded it shows net-flow, not the real balance. The Barclays Personal+Joint workbook has NO running-balance column, so those two current accounts need a manual opening balance to read true. Monzo exports DO carry a running `Balance` column (RHS verified: computed balance == the export's closing Balance, so RHS reads correctly). See [[MEM-004]].

### MEM-005 — Finance-Insights.html, the interactive analysis view (OPERATIONAL)
`Finance-Insights.html` in the workdir is Quinn's richer, interactive companion to the engine's `Finance-Dashboard.html`: month-by-month in/out trend by entity, collapsible sections, a mortgage paydown panel, an entity filter (All / Business only / per-world), and a regular-outgoings view that labels direct debits, flags possible overlapping commitments (e.g. multiple insurance lines), and excludes own-card repayments from the commitment total. Generated by `skills/finance-review/insights.py <workdir>` from `transactions.csv` + `rules/`; self-contained, never published. It reads the engine's output but does NOT modify the shared engine — a prototype. **Two follow-ons are architecture-class and held for Archy/Rex, not self-applied:** (a) folding proven features into `engine/dashboard.py`; (b) adding an "regenerate insights after consolidate" step to the routine contracts. Until (b), regenerate by hand after each run or the view goes stale. Built 2026-07-14 on Rex's request. See [[MEM-003]].

### MEM-004 — Card balance should be statement-authoritative (PROPOSED — architecture)
The Barclaycard balance computed by summing parsed transactions is unreliable: the adapter deliberately excludes interest/fees, so the sum drifts from the true balance and can even show the wrong sign. The statement's printed "your new balance" is authoritative. PROPOSED engine change: extend the mortgage authoritative-balance override (`analytics.py`) to `credit_card` accounts, keyed off the latest statement's control total. Held for Archy's counsel / Rex's ruling — touches the shared `consolidate` skill. Logged PROPOSED in `memory_log.md`.
